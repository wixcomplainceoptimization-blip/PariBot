# 🎲 PariBot - Telegram Betting Bot

Simple Telegram betting bot with balance tracking and match predictions.

## Commands

- `/start` - Welcome message
- `/help` - Help message
- `/balance` - Check your balance
- `/bet <amount>` - Place a bet (50/50 win chance)
- `/predict <league>` - Get match predictions
- `/leagues` - Show supported leagues

## Deployment

1. Push to GitHub
2. Connect to Railway
3. Add environment variables:
   - `BOT_TOKEN`
   - `ODDS_API_KEY`
4. Deploy!
